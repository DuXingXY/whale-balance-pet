## 每个站点独立金额转换（1.7.0）

打开站点的“设置”，勾选 **启用本站金额转换**，填入 **转换比例**，选择 **显示币种：美元（USD）或人民币（CNY）**。

显示金额 = 接口金额 × 本站转换比例。例如接口显示 10，比例填 0.2、显示币种选 CNY，则显示 ¥2.00。比例表示“1 个接口金额单位相当于多少显示币种”；金额已经先经过接口适配器的 quota、账单除数或自定义倍率处理。可以按自己的充值价格、折扣或换汇比例填写；程序不会查询汇率，也不会在切换显示币种时自动调整比例。

每个站点分别设置；默认关闭以保留原金额和原币种。余额看板、桌宠气泡、扣款动画、订阅窗口金额、每日消耗和消费秒表使用同一转换设置，测试连接显示转换值与接口原值。余额悬停、金额明细及秒表提示提供原值和转换比例。

历史记录与秒表按接口原值保存，修改显示比例或显示币种会按新比例重新显示全部现有记录，不清空历史，也不产生扣款或中断计时。低余额阈值仍按接口原始金额设置，编辑页会明确标注；提醒通知显示转换后的余额。接口原始币种、额度类型或站点 Key 改变时仍遵循原有观测保护规则。

## 每日金额与消费秒表（1.6.0）

打开站点管理，在用量面板点击 **金额 / 秒表**。

- 今日卡片分别显示各站点的观测消耗金额；每日明细支持站点筛选及近 7 / 30 / 90 天范围。按香港时间（UTC+8）分日，保存近 90 天本机记录，重启后保留。旧版只有最近一天的观测记录，可导入这一天，无法补齐过去账单。
- 消费秒表选择一个站点后点“开始计时”，支持暂停、继续、结束和重置。开始、暂停、继续及运行中结束会查询余额，以成功采样为边界；查询失败保留当前状态，提示重试。暂停期间的消费不计入，充值不抵消已记录下降。结束后保留本次结果，重置不删除每日历史。
- 秒数每秒更新，金额按该站点设置的刷新间隔更新，也可以点“更新金额”。正在计时的站点即使关闭自动刷新也会采样；关闭管理窗口继续计时，退出程序后暂停，重开后可继续。异常退出恢复时冻结到最后一次成功采样时间；退出时尚未采样的下降无法统计。
- 金额来自同币种、同类型的余额采样下降，是观测值，无法区分消费、退款与调账，也不代表全天完整账单。首次采样显示 0 只是尚未观测到下降；缺失日期不补零。跨午夜的下降无法准确拆分，不计入每日金额；持续运行的秒表仍可累计跨午夜的下降。
- 各站分别显示，不做跨币种或跨站合计，以免共享钱包的多个 Key 重复计费。订阅窗口与无限额度未提供可统计的余额金额。币种或额度类型变化会暂停秒表。
- 金额记录存储在同一应用数据目录的 `spending.json`，不存 Key 或请求正文。更换站点地址、Key 或金额映射会重置该站点的金额历史并结束相关计时；修改名称、刷新间隔与提醒设置保留历史。删除站点移除相关金额历史。

## 每个 API Key 的仪表盘（1.5.0）

打开站点管理，在用量面板点击 **API 仪表盘**，选择站点 / Key；顶部可切换 7 / 30 / 90 天或累计范围，点击刷新按钮重新读取。

- 指标包括普通输入 Token、输出 Token、缓存写入 / 读取 Token、总 Token、请求次数、Token 缓存命中率及平均 Token / 请求。
- Token 缓存命中率 = 缓存读取 /（普通输入 + 缓存写入 + 缓存读取）；这是 Token 占比。无输入或缺少字段显示“—”，零用量仍显示 0。
- 趋势图的输入含缓存，输出以虚线表示；“查看每日明细”提供精确数值。没有返回的日期不补零；累计模式的指标为累计值，趋势和明细仍为近 90 天。
- 当前读取已配置 Sub2API 站点的 `/v1/usage` 接口，包括每日 `cache_write_tokens` 字段；接口可能只返回部分字段。其他余额适配器尚未接入用量接口，会显示“未提供统计”，不会根据余额推算 Token。
- 相同站点与 Key 的重复配置共用统计来源，跨站合计只计算一次；数据仅覆盖这些 Key。仪表盘展示 Token 统计，不采集请求正文或模型回答。

此功能使用本地脚本和 SVG 图表，没有新增依赖、远程字体或 Chromium 副本；更新后的实际大小以程序目录的文件总大小为准。

## 启动与配置


双击同目录 `WhaleBalance.exe`。无需安装 Node.js、Python 或原项目，也无需附着 Codex。请保留整个程序文件夹，不能只拷贝 exe。

首次启动会打开站点管理：

1. 点“添加站点”。BB API 可在“快速填写”中直接选中；填入自己的 API Key。
2. 点“测试连接”，结果会在管理窗口顶部弹出，无需滚动。失败时提示框居中，第一行简述错误，下方显示可选择复制的错误代码和诊断详情；可点“复制全部”或手动选择后 Ctrl+C。提示框可手动关闭，测试完成后 60 秒自动关闭。核对金额、币种和余额类型后再保存。
3. 继续添加其他站点。每家有独立 Key、刷新频率、提醒阈值，查询最多三个站点同时进行。暂停的是自动刷新，点击桌宠仍可手动查询。
4. 更换服务商时可添加新站，或编辑原站；更换域名必须提供新站的 Key。

没有内置真实 Key，也不会读取其他软件、浏览器或测试脚本中的凭据。预览图片中的金额是演示值。第一次实际运行列表为空。

## 桌宠操作

- 平时只显示角色；桌面没有设置、刷新、切换或收起按钮。
- **单击角色：播放 Ya1.mp3 音效、轻微压扁后回弹，刷新余额并弹出对话气泡。** 动画约 300 毫秒；遵循系统减少动态效果设置。
- 气泡使用用户提供的 DSniang02.png 深蓝轮廓与小圆点，只显示中转站名字和余额，金额放大加粗。刷新期间保留上一次余额，收到结果后更新；没有历史读数时显示“—”。查询失败后显示“—”，详细错误和上次成功值放在管理界面。
- 余额刷新后若减少，在对应金额右下角显示红色差额（例如 −$0.50），约 3.4 秒缓慢下落并淡出。首次读数、余额不变、充值增加或查询失败不会产生扣款动画；单站与多站均支持。
- 查询完成后开始计时，默认 10 秒自动收起。多站点较多时可在气泡中滚动，或在管理页增加显示时长。
- **右键角色直接打开管理界面。** 管理页设置“点击后查看”全部站点或选中单站；点站点卡片的“设为查看站点”选定单站。
- 管理页设置气泡停留 5 / 10 / 20 秒，或一直显示；Esc 可随时收起，下一次单击继续刷新并弹出。
- 管理页设置点击音效开关和音量，默认开启、音量 70%。桌面不显示音效控件。
- 管理页的“桌宠皮肤”可切换 Deepseek（默认蓝发）、Claude（橙发）、Gemini（紫发）、Codex（白发）、玲绪，并显示预览。切换立即生效，重启会保留选择；五款皮肤共享点击查询、音效、压扁回弹、拖动、吸附、单站/多站气泡等功能。皮肤图片按比例显示，紫发图上方的透明留白在显示时收起，白发图和玲绪图已处理为透明底。
- 鼠标点击或拖动不显示蓝色焦点框；仅用 Tab 键选中角色时显示键盘焦点提示。Enter / 空格可查询余额。
- 拖动角色只移动位置，不发起查询或播放音效。连续快速点击都会给出反馈，但不会重复发送查询。
- 全部站点模式会手动查询所有站点（包括暂停自动刷新的站点）；单站模式只查选定站点。
- 托盘菜单可再次显示桌宠。关闭管理窗口继续运行；退出请用托盘菜单的“退出”。
- 可设置置顶、大小、拖动边缘吸附。松开时角色可见轮廓距工作区边缘 32px 内会吸附；顶部吸附时气泡移到角色下方，其他位置优先放在上方，气泡始终保持在屏幕工作区。角色可贴近工作区边缘，不受透明留白阻挡。旧的越界位置会自动回到工作区内，禁止系统将桌宠窗口最大化或拉长。不更改系统开机启动设置。

1.4.4 更新后，请先完全退出旧程序，再启动同一个 exe。站点、Key 和已有设置自动保留，首次增加皮肤时仍使用默认皮肤；不需要重新添加站点。气泡按照参考图贴近角色头顶，随角色移动，并在顶部吸附时改到下方。名字位于气泡上方的小区域，金额位于下方的大区域；单站金额 38px 加粗，多站 23px 加粗，美元在气泡中显示为 `$56.9293` 这样的形式。

### 用量汇总（1.4.0）

管理页顶部按参考图展示紧凑深蓝用量面板，与管理页共用主题色，默认概览为两排六张统计卡与蓝色方格热力图。顶部可切换模型排行和站点汇总；悬停或用方向键可查看热力格的日期 / Token / 请求次数，也可展开“每日数据”查看表格。统计说明折叠在底部。支持 Sub2API `/v1/usage` 返回的 `usage.total`、`daily_usage`、`model_stats`，包括 BB API 这类兼容接口；实际可用字段取决于服务商部署。其他余额适配器暂显示“未提供”，不会从余额下降推算 Token。

- 近 7 / 30 / 90 天的 Token 与调用次数按每日记录合计；“累计”读取接口累计总量。累计模式的活跃天数、模型排行仍只查询近 90 天，并在界面标明。
- 活跃天数按 UTC+8 的调用日期跨站点去重，同一天使用多个 Key 仍算一天。常用模型按模型请求次数排名，相同模型名合并，不猜测别名是否属于同一模型。
- 统计只覆盖已保存的 Key（包括暂停余额自动刷新的站点），不代表账户下全部 Key。相同站点域名与相同 Key 的重复配置会去重，不同 Key 分别查询。余额共享与用量共享是不同概念。
- 缺失和查询失败显示“—”及原因，已提供数据的合计标明覆盖的 Key 数；零值正常显示 0。总 Token 使用接口字段，缓存是否计入由服务商定义；输入 / 输出字段不等于全部 Token。
- 打开管理页、修改站点或点“刷新用量”时更新，最多三个站点并发。仅进行只读查询，不发送模型推理请求。错误详情可展开选择复制；用量数据只在内存中保留，重开管理页重新查询。

## 支持的接口

接口兼容由服务商决定。能调用模型并不代表一定开放余额接口，网站登录后的页面也不一定接受 API Key。

| 类型 | 查询接口 | 金额含义 |
| --- | --- | --- |
| Sub2API / BB API | `GET /v1/usage` | 无限制 Key 读钱包 `balance`；限额 Key 读 `quota.remaining`；订阅显示日/周/月窗口 |
| OpenAI 兼容 billing | `/v1/dashboard/billing/subscription` 和 `/v1/dashboard/billing/usage` | 总额度减已用，通常已用为美分（默认除以 100，可改） |
| New API / One API | `GET /api/usage/token/` | 此 Key 的额度。`total_available` / `total_used` 和旧版 quota 字段均按原始 quota 换算，默认每 500000 对应一个金额单位，可改；无限 Key 不显示为零余额 |
| DeepSeek | `GET /user/balance` | 按接口返回币种读取 `balance_infos[].total_balance` |
| OpenRouter | `GET /api/v1/credits` | `total_credits - total_usage` 美元；需管理 Key |
| Moonshot | `GET /v1/users/me/balance` | `data.available_balance`；国内官方站为人民币 |
| 自定义 JSON | 用户配置的本站 GET / POST 路径 | 指定余额、可选已用字段及倍率；支持 `data.balance`、`items[0].balance` |

自定义支持 Bearer、原始 Authorization、自定义请求头和无认证。POST 只应配置服务商文档中的只读余额查询；认证 Key 放单独的 Key 输入框，不要放 URL 或 JSON 参数中。自定义参数及地址属于普通设置，会存入本机配置。

**不会跨币种合计，也不把钱包、Key 限额和订阅窗口混为同一种余额。** 缺少有效金额时显示错误，不按零处理。查询失败或重启后未完成首轮查询，管理页会标记“上次成功值 / 当前未确认”，气泡金额显示“—”。零余额是有效读数。

“今日观测下降”累计当日两次有效采样间的下降（UTC+8 分日），包括采样中间的离线时段；是本机观察值，无法区分账户消费、退款、服务商调账等变化，不能替代完整账单。充值不抵消已观测下降。

## 数据与隐私

设置和观测数据在 `%APPDATA%\WhaleBalance`（若自定义 `--data-dir`，则使用指定目录）。Key 使用 Electron safeStorage 的 Windows 系统加密，保存为密文；编辑时不回显。密文通常只能在原 Windows 用户环境解密，不能视为可跨电脑迁移的 Key 备份。

系统加密主要保护磁盘中的凭据；同一 Windows 用户权限下运行的其他程序仍可能访问。Key 在请求时会被解密，只发往你配置的站点；查询禁止跟随重定向。HTTPS 是默认要求，仅本机 localhost 允许 HTTP。程序不进行模型推理请求、不上传统计、不抓取完整账单，也不保存余额接口的原始响应。

低余额会在看板和气泡变色，并尝试发送 Windows 通知，同一站点在充值回阈值上方后可再次提醒。窗口订阅没有单一钱包金额，不使用钱包阈值提醒。

## 验证范围

BB API 的 `/v1/usage` 已由用户自己带 Key 测试成功。此交付没有读取用户的 Key，也没有自动导入真实账号；需要在本程序再填写一次。

其他适配器经过模拟接口验证；真实账号权限和网站兼容性需通过“测试连接”确认。核心测试覆盖：多站 Key 隔离、域名变更保护、金额类型、零值、账单单位、自定义字段、响应大小限制、错误脱敏、并发上限、低余额提醒、充值后的下降记录，以及编辑/删除后的旧响应丢弃。本机 Electron 界面检查覆盖添加/测试/保存/编辑/暂停/切换/删除/大小调整/收起展开和实际 Windows 加密。1.2.0 检查包括气泡轮廓渲染、仅站名和金额、MP3 解码与播放进度、300 毫秒形变及恢复、管理页静音/音量、拖动不查询、不播放音效。音频检查时测试页面静音，不修改系统音量。
